# Modelos de la interfaz

Esta carpeta reúne clases y modelos propios de presentación: formularios, estado de pantalla o datos adaptados para componentes de la web. Se pueden organizar por funcionalidad a medida que crezca la aplicación.

No se duplican aquí las entidades ni las reglas del negocio de la API. Para solicitudes y respuestas se usan los contratos públicos de `@agenda-app/shared`.
